# Uthra Kumar R. — Portfolio Website

A responsive, monochrome digital-sport portfolio starter built with Next.js App Router, React, TypeScript, and CSS. It includes a cinematic loading counter, oversized typographic hero, about and expertise sections, interactive client carousel, campaign cards, performance case studies, career timeline, education, and contact details.

## Run locally

1. Install Node.js 18.17+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Before publishing

- Replace CSS-generated art and placeholder image areas with approved client logos, campaign assets, and photography.
- Verify all client names, dates, campaign labels, and performance metrics.
- Review phone, email, and LinkedIn details before public release.
- Add a PDF portfolio and downloadable CV if desired.

This is a local project starter; it is not deployed to a public URL.
