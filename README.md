# Uthra Kumar R. — Portfolio Website

A responsive, monochrome digital-sport portfolio starter built with Next.js App Router, React, TypeScript, and CSS. It includes a cinematic loading counter, oversized typographic hero, about and expertise sections, interactive client carousel, campaign cards, performance case studies, career timeline, education, and contact details.

## Run locally

1. Install Node.js 18.17+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.
